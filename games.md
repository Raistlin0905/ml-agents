# ML-Agents Training Environments

## All Available Environments
- **Basic:** Linear movement task where agent reaches rewarding states
- **3DBall:** Agent balances ball on a platform
- **3DBallHard:** Increased difficulty of 3DBall
- **Visual3DBall:** 3DBall with visual camera observations
- **GridWorld:** Grid-based navigation with multiple goals and obstacles
- **PushBlock:** Agent pushes block to goal location
- **PushBlockWithInput:** Interactive block pushing with player input
- **PushBlockCollab:** Cooperative multi-agent block pushing
- **WallJump:** Agent jumps over wall to reach goal
- **Crawler:** Four-armed creature locomotion toward goal
- **Worm:** Serpentine creature with head and three body segments moves toward goal
- **Walker:** Humanoid bipedal locomotion with 26 degrees of freedom
- **FoodCollector:** Multi-agent competitive resource collection avoiding negative items
- **VisualFoodCollector:** FoodCollector with visual camera observations
- **Hallway:** Memory-based navigation requiring block color recall
- **Pyramids:** Sequential task requiring button press, pyramid destruction, and goal reach
- **Match3:** Match-3 puzzle game with dynamic piece mechanics
- **Sorter:** Agent visits randomly positioned tiles in ascending order
- **SoccerTwos:** 2v2 competitive soccer game
- **StrikersVsGoalie:** 2v1 soccer variant with asymmetric roles
- **DungeonEscape:** Three-agent cooperative dungeon navigation
